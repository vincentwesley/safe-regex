safe-regex playground

A JavaScript-compatible regex engine that matches in linear time. Draw the automaton for a pattern, race it against your browser's built-in engine on a hostile input, and check which of your patterns would blow up.

The automaton a backtracking engine explores (ε-free NFA): each node consumes one character class from the pattern; an edge marked ×2 can be taken along two different paths, and nodes outlined in red belong to the part of the pattern the ReDoS checker blames — together, the ambiguity that makes backtracking explode. Hover a node to see its part of the pattern. SafeRegExp runs the same automaton as a Pike VM: all paths at once, one pass over the input.
